## 技术实现方案

### 1. Hero 区域
- 使用全宽大图背景（复用首页背景图 `/images/Eve 自宅雑談_2_prob4.webp`）
- 居中展示：大头像 + 名字 + 副标题 + 社交图标
- 深色渐变遮罩保证文字可读性
- 响应式设计：移动端头像缩小，文字居中

### 2. 个人简介卡片
- 白色/深色背景卡片（根据主题自动切换）
- 支持 Markdown 渲染页面内容
- 圆角 + 阴影（Material Design 风格）

### 3. 时间线组件
- 垂直时间线设计
- 左侧时间，右侧内容卡片
- 节点使用紫色主题色 (#7c4dff)
- 悬停效果：卡片上浮 + 阴影增强

### 4. 技能展示
- 网格布局展示技能卡片
- 每个卡片包含：图标 + 技能名 + 熟练度进度条
- 进度条使用紫色渐变

### 5. 数据统计
- 4 列网格展示关键数据
- 数字使用大字号 + 动画计数效果
- 数据从 Hexo 站点数据动态获取

## 样式设计

### 颜色方案
- **主色调**: #7c4dff (紫色)
- **背景**: 跟随主题 (light/dark)
- **文字**: var(--text-1), var(--text-2)
- **卡片**: var(--bg-1) + 边框阴影

### 动画效果
- 页面加载：淡入 + 上浮动画
- 滚动触发：元素依次淡入
- 悬停：卡片上浮 + 阴影加深
- 数字：计数动画

## 需要修改的文件

1. `themes/my-theme/layout/about.ejs` - 主模板
2. `themes/my-theme/source/css/about.scss` - 样式文件（新建）
3. `source/about/index.md` - 页面内容配置
