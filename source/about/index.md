# 欢迎来到我的数字花园

你好，我是 **悠久之翼**（Eternal Wings），一名热爱技术的全栈开发者，同时也是一位业余摄影爱好者。这个博客是我记录技术成长、分享摄影作品以及表达个人思考的数字空间。

## 技术之旅

我对编程的热爱始于大学时期，从最初的 Python 脚本到后来深入前端开发，技术之路虽不平坦，但每一步都充满收获。我专注于现代 Web 开发，熟练运用 **React** 和 **Vue** 构建高性能的用户界面，同时对 **Node.js** 后端开发也有深入研究。

在工程化方面，我热衷于探索最佳实践，包括代码规范、自动化测试、CI/CD 流程等。我相信好的代码不仅要能运行，更要易于维护和扩展。

## 开源与社区

我坚信开源精神的力量。在工作之余，我积极参与开源社区，为一些项目贡献代码，也在 GitHub 上分享自己的项目和工具库。这种协作文化不仅让我学到了更多，也让我结识了许多志同道合的朋友。

## 镜头下的世界

当代码编辑器关闭，我会拿起相机探索城市的角落。**摄影**是我观察世界的另一种方式——光影、色彩、构图，每一帧都是对美的追寻。技术让我理性思考，摄影则让我感性体验。这两种看似截然不同的爱好，在我心中达成了奇妙的平衡。
